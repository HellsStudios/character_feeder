# Character Feeder — Digest & Stages v2

Обновление предыдущей версии `character_feeder_evolution.zip`.
Основное кормление, физика перетаскивания, `gulp` и анимация живота сохранены.

## Как запустить

1. Распакуйте архив в **новую** папку.
2. Откройте `project.godot` в Godot (в настройках исходного проекта указана версия 4.7; Godot 4.4.1 не гарантирован).
3. Откройте `res://scenes/main.tscn` и запустите игру (F5).
4. Слева создавайте жертв, перетаскивайте их к пасти. После глотка растут живот и **Belly points**.
5. Нажмите **Digest**: рот открыт, живот плавно уменьшается 2 секунды, звучит (сейчас бесшумный) WAV, очки переводятся в **Banked points**.
6. Потратьте накопленные очки на **Auto Feed** и **Unlock Stage II/III**.

Сохранение от прошлой версии совместимо: `user://character_feeder_save.json` с ключами `bank_score`, `stage`, `auto_unlocked`.

## Изменения v2

- Английские надписи во всём новом игровом UI: Belly points, Banked points, Stage, Auto Feed, Unlock Stage II/III, Digest.
- В `assets/` созданы **настоящие отдельные файлы** `pred_2.png`, `pred_3.png`, `background_2.png`, `background_3.png`. Пока они бит-в-бит равны исходникам; никаких синих наложений и `modulate` для смены стадий не используется. До ручной перерисовки отличить стадии по внешности нельзя — число стадии показывает интерфейс.
- Третья стадия с собственным лимитом живота/очков и шансом редких жертв.
- `sounds/digest_placeholder.wav`: валидная бесшумная 2.0-секундная аудиодорожка. Проигрывается в `Predator/DigestAudioPlayer` **весь период Digest**. Замените WAV собственным 2-секундным звуком под тем же именем; при смене длительности меняйте также `DIGEST_DURATION`.
- Редкий розовый заяц: `#ff8dc9`, надпись `★ RARE`, +60 очков. На стадии II выпадает с вероятностью 15% от всех новых жертв. На стадии III общий шанс редкой жертвы 25%, добавляется золотой бобёр (+85).
- Цена следующей стадии подставляется автоматически из конфигурации; третья стадия больше не требует изменения основного менеджера.

## Где менять баланс — `scenes/game_balance.gd`

**Всё самое частое теперь находится в одном месте:**

```gdscript
const STAGES := {
    1: {
        "unlock_cost": 0,
        "score_limit": 120.0,
        "belly_limit": 1.8,
        "score_decay_per_second": 1.0,
        "belly_decay_per_second": 0.02,
        "rare_chance": 0.0,
        "predator_texture": "res://assets/pred.png",
        "background_texture": "res://assets/Bliss_(Windows_XP).png"
    },
    # ... данные для стадий 2 и 3
}
```

| Стадия | Стоимость открытия | Лимит очков в животе | Лимит живота | Убывание очков/с | Убывание размера/с | Шанс редкой жертвы |
|---|---:|---:|---:|---:|---:|---:|
| I | 0 | 120 | 1.8× | 1.0 | 0.020 | 0% |
| II | 240 | 360 | 2.6× | 0.6 | 0.012 | 15% |
| III | 720 | 900 | 3.4× | 0.35 | 0.008 | 25% |

Другие настройки в том же файле:

```gdscript
const AUTO_FEED_COST: int = 80
const AUTO_FEED_INTERVAL: float = 8.0
const DECAY_DELAY: float = 10.0
const DIGEST_DURATION: float = 2.0
```

**Как добавить стадию IV:**

1. Сделайте новые файлы `assets/pred_4.png` и `assets/background_4.png`.
2. Вставьте запись `4: {...}` в `STAGES`: цена, лимиты, скорость убывания, шанс редкости и пути текстур.
3. Запустите игру: менеджер сам покажет `Unlock Stage IV` после III, спишет указанную цену, подставит текстуры и новые лимиты. Структура стадии должна быть такой же, как у II/III. Номера должны идти подряд.

### Внешность персонажей

- Файлы `assets/pred.png`, `pred_2.png`, `pred_3.png` — **1434 × 2152**, спрайт-лист **2 столбца × 3 строки**; менять его размер и сетку не нужно. Хищник состоит из двух `Sprite2D` (тело и живот), `predator.set_stage_texture()` меняет оба.
- Фоны `Bliss_(Windows_XP).png`, `background_2.png`, `background_3.png` — **365 × 274**. Их желательно редактировать без изменения размера.
- Для изменения внешности стадии просто замените PNG соответствующего этапа с сохранением имени. Перезапустите проект или попросите редактор Godot переимпортировать ресурс.
- Пока все четыре новых файла — без перекраски: они копии. После замены изображений разница станет видна непосредственно в игре.

## Добавление жертв

### Вариант той же зверушки (без новой анимации)

В `scenes/game_balance.gd` расширьте `PREY_TYPES`:

```gdscript
"blue_raccoon": {
    "base_animal": "raccoon",
    "points": 100,
    "tint": "#76baff",
    "rare": true,
    "min_stage": 3,
    "spawn_weight": 0.5
},
```

Это уже работает: `edible_spawner.gd` включает все редкие варианты, доступные текущей стадии, и выбирает по `spawn_weight`. В примере с `rare_rabbit` (вес 1.0), `rare_beaver` (1.0) и `blue_raccoon` (0.5) — на III стадии пропорции **40% / 40% / 20% среди редких**. Общая вероятность редкого появления задаётся `rare_chance` у стадии.

`base_animal` указывает, какие кадры/анимации используются, `points` — награда, `tint` — цвет поверх спрайта, `rare` — значок RARE, `min_stage` — минимальная стадия.

### Полностью новый вид (с новой анимацией)

1. Откройте `scenes/edible.tscn`. В спрайт-листе `assets/prey_spritesheet.png` сейчас сетка **3 × 5**; добавьте кадры нового вида и подберите новые `hframes/vframes`, не ломая существующую разметку.
2. В `scenes/edible.tscn` у `AnimalAnimationPlayer` добавьте анимацию бега нового вида, соответствующую кадрам.
3. В `scenes/edible_frame_controller.gd` добавьте запись в `animals` с индексами `resting`, `falling`, именем `running`.
4. В `game_balance.gd/PREY_TYPES` добавьте `"new_species"` c `base_animal: "new_species"` и ценой в очках.
5. Обычный вид попадёт в случайный выбор **автоматически**, поскольку `choose_animal()` берёт ключи из `animals`. Если же это редкий вариант с `rare: true`, он попадёт в редкий пул без правок `edible_spawner.gd` (при условии, что его `min_stage` уже достигнут).

## Где менять звук

- В панели Scene откройте `Predator` (двойной клик по экземпляру, **Open in Editor**) → `DigestAudioPlayer`.
- В Inspector в поле **Stream** указан `res://sounds/digest_placeholder.wav`.
- Можете заменить этот файл готовым WAV, либо назначить в Inspector другой AudioStream.
- Срабатывание запускается в `scenes/predator.gd → start_digest_animation()` через `digest_audio_player.play()`; `stop()` происходит в `finish_digest_animation()`.
- Длина анимации регулируется `game_balance.gd → DIGEST_DURATION`. Звук-глушилка ровно 2.0 с. При звуке иной длительности делайте длительность анимации такой же или подготовьте аудио нужной длины.
- Дополнительный звук обычного глотка остаётся на узле `Predator/AudioStreamPlayer`.
